# ServerMonitor — редизайн фронтенда «Инструментальная сетка»

**Дата:** 2026-08-25
**Ветка:** feature/redesign
**Область:** только ServerMonitor.Web — CSS (wwwroot/app.css, *.razor.css), разметка .razor (без блоков `@code`), при необходимости wwwroot/js для визуальных эффектов. Бэкенд-проекты (Api, Infrastructure, Domain) не затрагиваются.

## Цель

Уйти от шаблонного «AI-сгенерированного» вида (карточки 20px со скруглениями, мягкие двойные тени, пастельные иконки-чипы, пилюля-навигация, каскадный fadeInUp, Inter) к характерному направлению: **швейцарская типографическая сетка на уровне страницы + эстетика измерительного прибора на уровне данных**. Сохранить всю функциональность и обе темы.

## Инварианты (не нарушать)

- Ни одна строка в блоках `@code` не меняется; все `@onclick`, `@bind`, вызовы ApiClient, параметры компонентов сохраняются.
- Система тем через `data-theme="light|dark"` на `<html>` и CSS-переменные сохраняется; `themeManager` (js/theme.js) не ломается.
- `navpill.js` (позиционирование индикатора навигации) продолжает работать — меняется только стилизация индикатора.
- Radzen-график остаётся (перекрашивается через CSS/параметры Stroke в разметке).
- Bootstrap остаётся подключённым (используется Radzen'ом), но визуальный язык задаётся нашими стилями.

## 1. Типографика

- **IBM Plex Sans** (400/500/600) — заголовки, навигация, текст UI.
- **IBM Plex Mono** (400/500/600) — все данные: значения метрик, временные метки, значения таблицы History, статусная строка, инпуты Settings, микро-метки.
- Подключение через Google Fonts в App.razor (заменить текущий Inter-линк).
- Микро-метки: Plex Mono 11px, UPPERCASE, letter-spacing 0.08em, цвет muted: `CPU USAGE`, `MEMORY`, `01 — LIVE METRICS`.
- Крупные значения метрик: Plex Mono 40–44px, `font-variant-numeric: tabular-nums` (цифры не прыгают при 5-секундном обновлении).
- Заголовки страниц: Plex Sans 600, 26–28px, letter-spacing −0.01em.

## 2. Палитра и темы

Существующие переменные (`--bg`, `--surface`, `--surface-2`, `--text`, `--text-muted`, `--text-soft`, `--border`, `--accent`, `--accent-hover`, `--accent-soft`) сохраняют имена — меняются значения. Тени (`--shadow`, `--shadow-hover`) обнуляются/убираются из использования.

**Светлая («инженерная бумага»):**
- `--bg: #f6f6f3` (тёплый белый), `--surface: #fdfdfb`, `--surface-2: #efefe9`
- `--text: #16181a`, `--text-muted: #6a6f6b`, `--text-soft: #9a9f99`
- `--border: #e0e0d8` (hairline)
- `--accent: #0d9f4f` (фосфорный зелёный, затемнён для контраста на бумаге), `--accent-hover: #0b8442`, `--accent-soft: rgba(13,159,79,0.10)`

**Тёмная («графит + фосфор»):**
- `--bg: #0e0f11`, `--surface: #131518`, `--surface-2: #191c20`
- `--text: #e6e8e4`, `--text-muted: #8e948d`, `--text-soft: #5d635c`
- `--border: #23262a`
- `--accent: #2ee66b` (фосфорный ЭЛТ-зелёный), `--accent-hover: #4dff85`, `--accent-soft: rgba(46,230,107,0.12)`

**Статусные цвета данных (новые переменные):**
- `--status-ok` = семейство акцента (зелёный), `--status-warn: #d99a06` / тёмная `#e8b93e`, `--status-crit: #d43d2a` / тёмная `#ff5c4a`.
- Пороговая логика остаётся прежней (≥90 crit, ≥70 warn), захардкоженные hex в MetricCard.BarColor не трогаем (это `@code`). Так как цвет бара приходит инлайн-стилем, в CSS используем атрибутные селекторы для перевода на новые переменные: `.metric-bar-fill[style*="#10b981"] { background: var(--status-ok) !important; }` (аналогично для `#f59e0b` → warn, `#ef4444` → crit). Там, где цвет задаётся классами (History `UsageClass`), — обычные CSS-классы.

Никаких теней и градиентов. Скругления 0–2px.

## 3. Сетка и поверхности

- **Dashboard**: четыре карточки метрик объединяются в **единую панель-стойку**: контейнер с 1px-рамкой, ячейки разделены 1px-линиями (grid + gap:1px на фоне цвета границы, либо border-right/bottom). Hover ячейки — фон `--surface-2`, без transform.
- Разметка `.cards-grid` / `MetricCard` меняется только в HTML-части; параметры компонента (Title, Value, Percent, Subtitle, Icon...) сохраняются. Пастельные IconBg-чипы уходят: иконка становится маленькой (16px) monochrome-меткой рядом с CAPS-заголовком (параметры IconBg/IconColor могут игнорироваться стилями, но остаются в сигнатуре).
- Секции получают нумерованные mono-заголовки: `01 — LIVE METRICS`, `02 — PERFORMANCE HISTORY` (History: `01 — LOG`, Alerts: `01 — EVENTS`, Settings: `01 — THRESHOLDS`, `02 — NOTIFICATIONS`).
- Углы главной панели украшены крестиками `+` (blueprint-метки) через ::before/::after или маленькие абсолютные элементы.
- **Прогресс-бары → шкалы**: высота 4px, острые углы, риски-деления на 25/50/75% (repeating-linear-gradient или псевдоэлементы), цвет заполнения по статусу.

## 4. Компоненты и страницы

- **TopNav**: убрать пилюлю и фон у ссылок; плоские ссылки Plex Mono 13px; активная — underline-черта 2px цвета акцента; `#navIndicator` перестилизуется в полосу под ссылками (JS не меняется). Логотип: mono `SERVER_ML` или Plex Sans 600 + акцентная часть; sticky-шапка с 1px нижней границей, лёгкий backdrop-blur допустим.
- **Кнопки** (refresh/pause/apply/save): плоские, 1px-рамка, острые углы, mono-текст; primary — заливка акцентом (текст: тёмный на фосфорном в dark, белый в light — проверить контраст).
- **History**: таблица-«журнал»: mono-цифры, hairline-строки, hover-подсветка строки; бейджи-пилюли → значение + статусная точка (8px квадрат/круг) слева, цвет по `UsageClass`; заголовки колонок CAPS mono 11px; пагинация — плоские mono-кнопки.
- **Alerts**: список с вертикальной осью слева (border-left 1px, маркеры-узлы на оси); эмодзи ⚠️/✅ в разметке → SVG-маркеры в статусных цветах; mono-время справа; текст события Plex Sans.
- **Settings**: строки формы разделены hairline; number-инпуты — mono, плоские, только нижняя граница (или 1px-рамка), фокус — граница акцентом без box-shadow; тумблер → прямоугольный «приборный» switch (прямые углы, движущийся квадратный бегунок); сообщение о сохранении — mono.
- **Radzen-график**: Stroke-параметры серий в разметке → новые цвета (CPU — фосфорный зелёный, Memory — нейтральный серо-синий `#7a8ba6`/dark `#8fa3c0`, Disk — янтарный warn); оси/сетка — `--border`; текст — mono через CSS-override; легенда снизу.
- **Состояния** (Loading/error/empty): плоские панели с 1px-рамкой, mono-текст; `⚠` в error-состояниях допустимо заменить на mono-префикс `[ERR]`.
- **Статусная строка Dashboard**: `● LIVE · updated HH:mm:ss` — Plex Mono, точка пульсирует акцентом; paused — янтарная.

## 5. Движение

- Удалить каскадный fadeInUp и `card-anim`-задержки; страница появляется одним fade 150–200ms (или без анимации).
- Убрать hover-`translateY` и тени повсюду.
- Сохранить: transition ширины баров, пульс live-точки, слайд nav-индикатора, spin иконки refresh.
- Тумблер темы (ThemeToggle с облаками/звёздами) — сохранить функциональность; допустимо упростить стилистику под новый язык, не меняя `@code`.

## 6. Критерии готовности

- Обе темы полностью работают, переключение без FOUC-артефактов.
- Ни один блок `@code` не изменён (проверка diff).
- Все страницы (Dashboard, History, Alerts, Settings, NotFound/Error) переведены на новый язык — ни одного места со старыми тенями/скруглениями 20px.
- Контраст текста и акцентов ≥ WCAG AA на обеих темах.
- Проект собирается (`dotnet build`), страницы визуально проверены в браузере в обеих темах.

## Phase 2 — «Оживление» (утверждено 2026-08-25)

Пользователь снял ограничение на изменение кода: менять `@code`/бэкенд можно, если логика проекта не рушится. Цель — убрать «пустоватость» и заменить чужеродный Radzen-график.

1. **Канальный график («осциллограф»)** вместо RadzenChart: три полосы CPU/MEM/DISK, кастомный SVG (polyline + полигон-заливка ~10% непрозрачности, сетка-линии, vector-effect: non-scaling-stroke), метка канала слева (`CH1 · CPU · тек.значение`), общие метки времени внизу, переключатель периода сохраняется. Хелпер `ChartPoints(...)` в `@code` с инвариантным форматированием. Тултипы Radzen не сохраняются (осознанно).
2. **Sparkline в MetricCard**: новый опциональный параметр `Spark` (готовая строка points), тонкая линия истории под значением. Uptime — без спарклайна.
3. **Терминальный курсор** `▍` (CSS-blink) рядом с LIVE + **flash значений** при обновлении: `wwwroot/js/liveflash.js` (MutationObserver добавляет класс `value-flash`).
4. **Blueprint-сетка** фоном страницы: два 1px linear-gradient, шаг 28px, токен `--grid-line` (~3% контраста) в обеих темах.
5. **`03 — SESSION STATS`**: строка avg/max по трём метрикам + samples + uptime, вычисляется из `history`.
6. **3D-штрих**: CSS-wireframe-куб (6 граней, border фосфорного цвета, rotateY 16s linear infinite, `paused` при паузе) в шапке дашборда. `prefers-reduced-motion` отключает куб/курсор/flash.
7. **Чистка**: удалить неиспользуемые `chart`-поле (CS0169) и `FormatTime`; убрать Radzen-ссылки (css/js/RadzenComponents) — пакет остаётся установленным.
