# Гайд по проекту ServerMonitor

Разбор собственного проекта «до последней строчки»: как он устроен, почему устроен именно
так, и что стоит за каждым используемым механизмом .NET.

Это **учебник по коду этого репозитория**, а не документация продукта. Он написан для
одного читателя — автора проекта, который изучает бэкенд-разработку и хочет понимать
каждую деталь, а не просто иметь работающее приложение.

## Как читать

Главы идут по нарастанию: сначала общая карта, потом язык, потом каждый слой отдельно.
Если что-то непонятно — скорее всего, объяснение было в предыдущей главе.

этапы, на которых система научилась следить за парком машин, замечать их пропажу, закрываться
от посторонних и запускаться одной командой. Дальше гайд растёт вместе с проектом: каждый новый
этап разработки завершается своей главой.

## Соглашения

- **Термины** дублируются английскими: «внедрение зависимостей (dependency injection, DI)» —
  именно английские слова встретятся в документации и в вакансиях.
- **Ссылки на код** ведут на реальные файлы репозитория; номера строк указаны на момент
  написания главы и могут сдвинуться после правок.
- Блок **«Почему так»** объясняет выбор решения и альтернативы.
- Блок **«Слабое место»** честно называет технический долг и баги. Их наличие — норма для
  учебного проекта; важно про них знать.
